# Assistente de Migração

Execute migrações de sistemas abrangentes com capacidades de planejamento, verificação e reversão: **$ARGUMENTS**

## Contexto Atual de Migração

- Sistemas de origem: Status de autenticação e acesso à API do GitHub CLI
- Sistemas de destino: Conectividade e permissões do servidor MCP Linear
- Armazenamento de backup: Espaço de armazenamento disponível e verificação de backup
- Escopo da migração: Estimativa de volume de dados e avaliação de complexidade

## Tarefa

Execute processo sistemático de migração com medidas de segurança abrangentes e validação:

**Ação de Migração**: Use $ARGUMENTS para especificar operações de planejamento, análise, execução, verificação ou reversão de migração

**Framework de Migração**:
1. **Validação de Pré-requisitos** - Verifique autenticação do GitHub CLI, confirme conectividade do MCP Linear, valide permissões, garanta armazenamento de backup
2. **Planejamento de Migração** - Avalie volume de dados e complexidade, projete estratégia de migração, identifique dependências, crie plano de reversão
3. **Análise de Risco** - Avalie possíveis pontos de falha, analise riscos de integridade de dados, identifique dependências do sistema, planeje medidas de contingência
4. **Gerenciamento de Execução** - Implemente fases de migração, monitore progresso e integridade, trate erros com elegância, mantenha trilhas de auditoria
5. **Processo de Verificação** - Valide integridade de dados, confirme funcionalidade do sistema, teste fluxos de trabalho do usuário, verifique métricas de desempenho
6. **Procedimentos de Reversão** - Implemente mecanismos seguros de reversão, restaure estado do sistema, valide recuperação, comunique atualizações de status

**Recursos Avançados**: Suporte para migração incremental, monitoramento de progresso em tempo real, verificações de integridade automatizadas, logging abrangente, mecanismos de parada de emergência.

**Medidas de Segurança**: Backups em múltiplos pontos, validação de integridade, testes de reversão, monitoramento de integridade do sistema, comunicação com stakeholders.

**Output**: Execução completa de migração com rastreamento de progresso, relatórios de validação, prontidão para reversão e recomendações de otimização pós-migração.
