# Modo IA Aprimorado para Tarefas Complexas

Modo IA aprimorado para tarefas complexas

*Comando originalmente criado por IndyDevDan (YouTube: https://www.youtube.com/@indydevdan) / DislerH (GitHub: https://github.com/disler)*

## Instruções

Inicialize uma nova sessão Claude Code com contexto abrangente do projeto:

1. **Analisar Estrutura do Codebase**
   - Execute `git ls-files` para compreender a organização de arquivos e layout do projeto
   - Execute comandos de árvore de diretórios (se disponível) para estrutura visual
   - Identifique diretórios principais e seus propósitos
   - Observe o stack de tecnologia e frameworks em uso

2. **Ler Documentação do Projeto**
   - Leia README.md para visão geral do projeto e instruções de configuração
   - Verifique documentação adicional em docs/ ou ai_docs/
   - Revise CONTRIBUTING.md ou guias de desenvolvimento
   - Procure por documentos de arquitetura ou design

3. **Compreender Contexto do Projeto**
   - Identifique o propósito e objetivos principais do projeto
   - Anote quaisquer requisitos especiais de configuração ou dependências
   - Verifique necessidades de configuração de ambiente
   - Revise quaisquer arquivos de configuração de CI/CD

4. **Fornecer Visão Geral Concisa**
   - Resuma o propósito do projeto em 2-3 frases
   - Liste as principais tecnologias e frameworks
   - Destaque quaisquer etapas importantes de configuração
   - Anote áreas principais do codebase

Este comando ajuda a estabelecer contexto rapidamente quando:
- Iniciando trabalho em um novo projeto
- Retornando a um projeto após tempo de afastamento
- Integrando novos membros da equipe
- Preparando trabalho técnico profundo

O objetivo é "preparar" o assistente IA com conhecimento essencial do projeto para assistência mais eficaz.
