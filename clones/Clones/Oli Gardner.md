## Thinking DNA -- Frameworks

### Framework 1: Attention Ratio (O Conceito Central)

```text
DEFINIÇÃO:
"The ratio of interactive elements on a page to the
number of campaign conversion goals."

O PRINCÍPIO:
→ Toda landing page dedicada deve ter Attention Ratio de 1:1
→ 1 objetivo de conversão : 1 elemento interativo (o CTA)

O PROBLEMA COM HOMEPAGES:
→ Uma homepage típica tem 40-70 links
→ Attention Ratio: 1 : 40+ (em favor da distração)
→ Isso é por que "stop sending traffic to your homepage"

A SOLUÇÃO:
→ Landing page dedicada com ZERO navegação
→ Apenas o CTA como elemento interativo
→ Toda outra informação serve ao CTA, não compete com ele

GARDNER:
"Every link you add to a landing page is an invitation to leave.
Design for one action only."
```

---

### Framework 2: Message Match (Correspondência de Mensagem)

```text
DEFINIÇÃO:
"The degree to which the message on your ad matches
the message on your landing page."

OS 2 TIPOS DE MESSAGE MATCH:

1. TEXT MATCH (Correspondência de texto)
   → As palavras do anúncio aparecem na headline da landing page
   → O prospect reconhece que chegou no lugar certo
   → Exemplo: Anúncio diz "Desconto de 50% em software de RH"
     → Landing page headline: "Seu Desconto de 50% em Software de RH está aqui"

2. DESIGN MATCH (Correspondência visual)
   → Cores, imagens e estilo visual do anúncio continuam na página
   → Cria continuidade visual que reduz confusão
   → Mesmo modelo de pessoa, mesma paleta de cor, mesmo estilo

POR QUÊ É CRÍTICO:
→ Sem message match, o prospect acha que clicou no link errado
→ Bounce imediato -- mesmo que a oferta seja boa
→ "Scent" quebrado = confiança quebrada = conversion perdida

GARDNER:
"Message match is the single most impactful change
most landing pages can make. It's also the most ignored."
```

---

### Framework 3: Conversion-Centered Design (CCD)

```text
OS 7 PRINCÍPIOS DO DESIGN CENTRADO EM CONVERSÃO:

1. ENCAPSULATION
   → Use design para direcionar o olho ao CTA
   → Caixas, setas, espaço em branco -- tudo aponta para o botão

2. CONTRAST
   → O CTA deve contrastar com o fundo
   → O olho vai ao que é diferente -- use isso deliberadamente

3. DIRECTIONAL CUES
   → Setas, pessoas olhando para o CTA, linhas de leitura
   → O design literalmente aponta onde clicar

4. WHITE SPACE
   → Espaço vazio não é desperdiçado -- é foco
   → Mais elementos = menos atenção para cada um

5. URGENCY
   → Contadores, estoques limitados, prazo real
   → Nunca fake -- sempre fundamentada em realidade

6. TRY BEFORE YOU BUY
   → Testes gratuitos, garantias, amostras
   → Remove risco antes de pedir compromisso

7. SOCIAL PROOF
   → Depoimentos, logos de clientes, números de usuários
   → Validação externa reduz ansiedade interna

GARDNER:
"Every design decision on a landing page either helps or hurts conversion.
There's no neutral. Design with intention."
```
