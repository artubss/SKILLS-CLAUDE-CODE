# Robert McKee — Core Frameworks (Slim)

> Excerpt for pipeline context injection. Full: Clones/Robert McKee.md

## Story Structure Principles

### The Story Gap (Narrative Engine)

Every powerful narrative moment is born from a gap between:
- **Subjective expectation** — what the protagonist (or viewer) expected
- **Objective result** — what actually happened

The bigger the gap, the greater the tension and engagement.

### Progressive Complications

Each revelation must ESCALATE the conflict — never diminish it:

1. **Inciting Incident** — The event that breaks the initial equilibrium (must occur in the first 1/4)
2. **Progressive Complications** — Each block adds a layer of conflict (rising stakes)
3. **Crisis** — The moment of irreversible decision (most tense point)
4. **Climax** — The action taken in the crisis and its result
5. **Resolution** — The new equilibrium — never the same as the start

**Fatal error:** Blocks that don't complicate anything. If a block can be removed without changing the narrative, it must be removed.

### Scene Design (Value Turns)

Every scene has 2 questions:
1. What value is at stake? (love/hate, power/impotence, success/failure)
2. Did the value TURN by the end? (positive to negative or vice-versa)

If the value doesn't turn, it's not a scene — it's description. Rewrite.

### Subtexto

Don't narrate explicitly. Show the concrete detail that implies it:
- BAD: "The company was losing market fast"
- GOOD: "In 1994, 47 of 200 stores didn't open Monday. No warning. No notice."

## Key Patterns

- "Story is not what happens. Story is why it matters."
- "The gap between expectation and result — that's where story lives."
- Principle over formula: don't follow templates blindly — ask "is this block maximizing the gap?"
- "A scene that changes nothing doesn't exist."
