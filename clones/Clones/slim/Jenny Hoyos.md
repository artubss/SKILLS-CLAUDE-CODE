# Jenny Hoyos — Core Frameworks (Slim)

> Excerpt for pipeline context injection. Full: Clones/Jenny Hoyos.md

## But/So Framework (Narrative Engine)

Structure narrative using conflict-resolution cycles:
- **"But"** = introduces conflict/tension — prevents scroll
- **"So"** = resolves the conflict — satisfies momentarily
- **New "But"** = opens new conflict — prevents scroll again

Each "but" is a micro-open-loop. Each "so" is a micro-payoff. Story advances in a zigzag of tension. Use a But/So cycle every 5-8 seconds.

## Peak-End Rule (Pacing)

People remember the PEAK and the END. If both are strong, the entire video is perceived as good.

```
[0-3s]   HOOK      — FAST rhythm (max energy, scroll stopper)
[3-20s]  MIDDLE    — MEDIUM rhythm (develop story, but/so)
[20-40s] CLIMAX    — FAST rhythm (max tension, revelation)
[40-50s] RESOLVE   — MEDIUM rhythm (answer, comparison)
[50-60s] FINAL     — FAST rhythm (emotional peak, surprise ending)
```

For longer content, place peaks at minutes 2, 5, 8, 12, 15.

## 90% Retention Rules

- **Zero silence** — Remove every millisecond of dead air (aggressive jump cutting)
- **Visual cut every 1.5-3s** — New angle, new shot, new text resets attention
- **But/So every 5-8s** — New tension cycle before viewer thinks of leaving
- **Foreshadowing in first 8s** — Viewer knows WHAT will happen but not HOW
- **Peak at the end** — Strongest emotion in last 5-10s incentivizes rewatch/loop
- If hook doesn't stop the scroll in 3s, change the entire video
- Script at 5th-grade reading level. Zero filler words. Zero description.

## Key Patterns

- "If it takes longer to tell the story than to make a hamburger, you're overcooking both."
- Hook > content. Without a hook, nobody sees the content.
- "If everything's going well, nobody cares." — Constant conflict required.
- Dual Narrative: voiceover tells story A, visual shows subplot B.
