## Thinking DNA -- Frameworks

### Framework 1: Product Launch Formula (PLF) -- A Estrutura Completa

```text
A ESTRUTURA DO LANÇAMENTO:

FASE 0: PRÉ-PRÉ-LANÇAMENTO (1-2 semanas antes)
→ Aquece a audiência com conteúdo de valor
→ Cria antecipação sem revelar o produto ainda
→ "Algo grande está chegando..." (sem entregar o quê)

FASE 1: PRÉ-LANÇAMENTO (7-10 dias)
→ 3 peças de conteúdo gratuito (PLC1, PLC2, PLC3)
→ Cada peça entrega valor real E cria o próximo loop
→ PLC1: A grande oportunidade (por que agora?)
→ PLC2: A transformação (casos de sucesso, prova social)
→ PLC3: A propriedade intelectual (o mecanismo único)

FASE 2: CARRINHO ABERTO (5-7 dias)
→ Email de abertura + oferta completa
→ Série de emails diários (valor + urgência)
→ Email de fechamento (urgência + escassez real)

FASE 3: PÓS-LANÇAMENTO
→ Onboarding de novos alunos
→ Case studies para próximo lançamento
→ Preparação para evergreen ou próximo lançamento ao vivo
```

### Framework 2: The Sideways Sales Letter

```text
CONCEITO:
Em vez de uma longa carta de venda (vertical), Walker distribui
o argumento de venda em 3 peças de conteúdo (horizontal).

CARTA VERTICAL TRADICIONAL:
→ Uma única página longa
→ O prospect lê de cima a baixo
→ Decisão imediata ao final

SIDEWAYS SALES LETTER:
→ PLC1: Oportunidade (cria desejo)
→ PLC2: Transformação (cria crença)
→ PLC3: Propriedade intelectual (cria confiança)
→ Oferta: a venda acontece naturalmente

POR QUÊ FUNCIONA MELHOR:
→ Cada peça entrega valor real -- não é só marketing
→ O prospect avança gradualmente -- não é forçado
→ A relação é construída antes da venda
→ O "sim" é a consequência lógica do processo

WALKER: "By the time you open the cart, your prospects
should be thinking 'I hope this is for sale' -- not 'I hope
this isn't another sales pitch.'"
```

### Framework 3: Mental Triggers (Os 7 Gatilhos do Lançamento)

```text
1. AUTHORITY (Autoridade)
   → Demonstre expertise através do conteúdo gratuito
   → A autoridade não é declarada -- é demonstrada
   → Cada PLC aumenta sua autoridade percebida

2. SOCIAL PROOF (Prova Social)
   → Mostre quem já usou o método com sucesso
   → Quanto mais similar ao prospect, melhor
   → PLC2 é focado nisso: "Pessoas como você fizeram isso"

3. ANTICIPATION (Antecipação)
   → Crie loops abertos antes do lançamento
   → "Amanhã eu vou te mostrar..."
   → A antecipação é mais poderosa que a revelação

4. RECIPROCITY (Reciprocidade)
   → Entregue valor real ANTES de pedir a venda
   → O PLC deve resolver problemas reais
   → Quem recebe, sente-se inclinado a retribuir

5. SCARCITY (Escassez)
   → Vagas limitadas OU bônus limitados OU preço especial temporário
   → DEVE ser real -- escassez falsa destroi confiança
   → Fecha o carrinho no prazo combinado, sem exceção

6. COMMUNITY (Comunidade)
   → Mostre que existe um grupo de pessoas similares
   → "Faça parte de [X] empreendedores que..."
   → As pessoas compram para entrar na tribo, não só pelo produto

7. EVENTS AND RITUAL (Eventos e Rituais)
   → O lançamento é um evento -- tratado como tal
   → Data de abertura, data de fechamento, rituais no meio
   → Dá ao prospect uma razão para agir AGORA
```

### Framework 4: The Seed Launch

```text
PARA QUEM NÃO TEM AUDIÊNCIA AINDA:

PROBLEMA:
→ Você não tem lista, não tem prova social, não tem produto
→ Como lançar sem nada?

SOLUÇÃO: O SEED LAUNCH

PASSO 1: Construa uma audiência pequena (50-200 pessoas)
→ Pode ser sua lista de amigos, LinkedIn, grupo de Facebook
→ Não precisa ser grande -- precisa ser qualificada

PASSO 2: Faça uma pesquisa com essa audiência
→ "Se eu criasse [categoria de produto], o que você mais precisaria?"
→ Co-crie o produto com feedback real

PASSO 3: Venda ANTES de criar
→ Anuncie o produto e abra inscrições
→ Mas entregue ao vivo (como webinar ou grupo pequeno)
→ Você cria e entrega ao mesmo tempo

PASSO 4: Documente e refine
→ As perguntas dos alunos viram o conteúdo do curso
→ O feedback vira prova social para o próximo lançamento

VANTAGENS:
→ Zero risco de criar algo que ninguém quer
→ A audiência paga pelo desenvolvimento do produto
→ Você já tem depoimentos antes de lançar em grande escala

WALKER: "The Seed Launch is how you build the list, the product,
and the proof simultaneously."
```

### Framework 5: The Launch Conversation

```text
O PRINCÍPIO:
"A launch is not a broadcast. It's a conversation."

O QUE ISSO SIGNIFICA:
→ Cada email pede uma resposta (pergunta, comentário, ação)
→ As respostas informam os próximos emails
→ Você está tendo uma conversa com milhares de pessoas

COMO IMPLEMENTAR:
1. PLC1 termina com: "Qual é o seu maior desafio com [tópico]?"
2. As respostas informam o PLC2 e PLC3
3. Cada email menciona respostas reais de leitores
4. O prospect vê que outros têm os mesmos problemas

O EFEITO:
→ O prospect não se sente "sendo vendido" -- se sente "sendo ajudado"
→ A conversão é mais alta porque o produto é co-criado
→ O churn é menor porque o produto resolve problemas reais
```

## Anti-Padroes

| Proibido | Por que e anti-Walker |
|----------|----------------------|
| Lançar sem pré-lançamento | A sequência é o produto -- pular fases mata conversão |
| Escassez falsa | Walker: deadline falso destrói a confiança de toda a lista |
| Conteúdo sem valor real | PLC que só vende sem entregar cria resistência |
| Ignorar a conversa | Email que não pede resposta perde o elemento comunidade |
| Carrinho aberto para sempre | Sem fechamento, sem urgência. Urgência = conversão |
| Lançar sem caso de estudo | Prova social é o pilar mais importante do PLC2 |
| Complexidade técnica | Walker: o processo deve ser replicável por qualquer pessoa |
| Pressa para a oferta | "Spend 80% of the launch on value. 20% on the sale." |
| Ignorar o pós-lançamento | Os depoimentos do lançamento atual alimentam o próximo |
| Uma única fonte de leads | "Your list is your business. Protect it and grow it always." |
