## Thinking DNA -- Frameworks

### Framework 1: The Ask Method -- Core

```text
O PRINCÍPIO FUNDAMENTAL:
"Don't guess what your customer wants. Ask."

O PROBLEMA QUE O ASK RESOLVE:
→ Mercados são heterogêneos -- prospects diferentes têm necessidades diferentes
→ Marketing genérico converte menos porque não fala com ninguém especificamente
→ A solução: segmentar ANTES de comunicar

O PROCESSO EM 5 PASSOS:

1. DEEP DIVE SURVEY
   → Pesquisa aberta para entender o mercado em profundidade
   → "Qual é o seu maior desafio com [tópico]?"
   → Leia 100-200 respostas -- os padrões emergem

2. BUCKET SEGMENTATION
   → Agrupe as respostas em 3-5 "buckets" (segmentos)
   → Cada bucket representa um tipo diferente de prospect
   → Exemplo: "Iniciantes", "Intermediários frustrados", "Avançados em plateau"

3. QUIZ/SURVEY FUNNEL
   → Crie um quiz que automaticamente coloca cada prospect no bucket certo
   → Cada bucket recebe comunicação específica para suas necessidades

4. PERSONALIZAÇÃO DA MENSAGEM
   → Cada bucket recebe oferta e copy diferentes
   → O prospect sente que você fala exatamente com ele

5. ESCALA
   → O sistema funciona automaticamente
   → Cada novo prospect é segmentado e recebe comunicação personalizada
```

### Framework 2: The One Question (A Pergunta de Um Milhão)

```text
A PERGUNTA MAIS IMPORTANTE DO ASK METHOD:

"What is the #1 single biggest challenge you're facing
right now with [tópico]?"

POR QUÊ ESTA PERGUNTA ESPECÍFICA:
→ "Número 1" força uma priorização -- o prospect revela o que mais importa
→ "Single biggest" elimina respostas genéricas
→ "Right now" garante relevância atual
→ "Facing" implica ação, não só curiosidade
→ "With [tópico]" é específico o suficiente para ser útil

O QUE FAZER COM AS RESPOSTAS:
1. Leia as primeiras 100 respostas
2. Identifique as 3-5 palavras ou frases que aparecem repetidamente
3. Use essas EXATAS PALAVRAS em sua copy
4. O prospect pensa: "É como se você estivesse lendo minha mente"

LEVESQUE:
"When you use the exact words your prospect uses to describe
their problem, you achieve instant empathy and credibility."
```

### Framework 3: Bucket Segmentation

```text
O SISTEMA DE BALDES:

PASSO 1: IDENTIFIQUE OS BUCKETS
→ Após a Deep Dive Survey, os padrões emergem naturalmente
→ Geralmente 3-4 buckets distintos por mercado
→ Exemplo para mercado de emagrecimento:
   Bucket 1: "Nunca tentei dieta -- não sei por onde começar"
   Bucket 2: "Já tentei várias dietas mas sempre recupero o peso"
   Bucket 3: "Estou nos últimos 5 quilos e não consigo eliminar"

PASSO 2: CRIE UMA JORNADA PARA CADA BUCKET
→ Cada bucket tem medos, desejos e objeções específicos
→ Cada bucket precisa de uma sequência de emails diferente
→ Cada bucket pode precisar de produtos ou preços diferentes

PASSO 3: CRIE O QUIZ QUE SEGMENTA
→ 3-7 perguntas que identificam em qual bucket o prospect pertence
→ Cada resposta revela mais sobre a situação e necessidade
→ No final: "Com base em suas respostas, você é [tipo]"

PASSO 4: PERSONALIZAÇÃO AUTOMÁTICA
→ Email 1 para Bucket 1: resolve o problema de quem nunca tentou
→ Email 1 para Bucket 2: resolve o problema de quem sempre falha
→ Email 1 para Bucket 3: resolve o problema de quem está no plateau

O RESULTADO:
→ Taxa de abertura 40-60% maior
→ Taxa de conversão 2-5x maior
→ Churn menor (produto certo para pessoa certa)
```

### Framework 4: The Pebble in the Shoe

```text
CONCEITO:
"O maior problema que seu cliente tem nem sempre é o que ele
acha que é. É o 'pebble in the shoe' -- o pequeno incômodo
constante que está causando todos os outros problemas."

COMO IDENTIFICAR:
→ Na Deep Dive Survey, peça para descrever o dia problemático
→ "Descreva um dia quando [problema] foi especialmente frustrante"
→ Nas respostas, procure o detalhe específico que aparece repetidamente

EXEMPLO:
→ Em mercado de produtividade, o "big problem" declarado era "falta de tempo"
→ O "pebble" real: "Começo o dia sem saber o que priorizar"
→ A solução não precisava ser "mais tempo" -- precisava ser "clareza de priorização"

COMO USAR NA COPY:
→ Mencione o pebble especificamente -- antes do problema maior
→ "Você acorda de manhã e já sente aquela sensação de estar atrás..."
→ O prospect pensa: "Como ele sabe exatamente como me sinto?"
```
