# Image Enhancer

Esta skill pega suas imagens e screenshots e as deixa melhores—mais nítidas, claras e profissionais.

## Quando Usar Esta Skill

- Melhorar a qualidade de screenshots para blog posts ou documentação
- Aprimorar imagens antes de compartilhar em redes sociais
- Preparar imagens para apresentações ou relatórios
- Aumentar a escala de imagens em baixa resolução
- Nitidez em fotos desfocadas
- Limpar imagens comprimidas

## O Que Esta Skill Faz

1. **Analisa Qualidade da Imagem**: Verifica resolução, nitidez e artefatos de compressão
2. **Aprimora Resolução**: Aumenta a escala de imagens de forma inteligente
3. **Melhora Nitidez**: Aprimora bordas e detalhes
4. **Reduz Artefatos**: Remove artefatos de compressão e ruído
5. **Otimiza para Caso de Uso**: Ajusta conforme o uso pretendido (web, impressão, redes sociais)

## Dicas

- Sempre mantém arquivos originais como backup
- Funciona melhor com screenshots e imagens digitais
- Pode processar em lote pastas inteiras
- Especifique o formato de saída se necessário (PNG para qualidade, JPG para tamanho menor)
- Para redes sociais, mencione a plataforma para dimensionamento ideal

## Casos de Uso Comuns

- **Blog Posts**: Aprimora screenshots antes de publicar
- **Documentação**: Deixa screenshots de UI cristalinos
- **Redes Sociais**: Otimiza imagens para Twitter, LinkedIn, Instagram
- **Apresentações**: Aumenta a escala de imagens para telas grandes
- **Materiais Impressos**: Aumenta resolução para mídia física
