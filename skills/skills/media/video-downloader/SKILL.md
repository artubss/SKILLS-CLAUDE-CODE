# Video Downloader

Esta skill baixa vídeos do YouTube e outras plataformas diretamente para seu computador.

## Quando Usar Esta Skill

- Baixar vídeos do YouTube para visualização offline
- Salvar conteúdo educacional para referência
- Arquivar vídeos importantes
- Obter arquivos de vídeo para edição ou reutilização
- Baixar seu próprio conteúdo de plataformas
- Salvar palestras de conferências ou webinars

## O Que Esta Skill Faz

1. **Baixa Vídeos**: Obtém vídeos do YouTube e outras plataformas
2. **Seleção de Qualidade**: Permite escolher resolução (480p, 720p, 1080p, 4K)
3. **Opções de Formato**: Baixa em vários formatos (MP4, WebM, apenas áudio)
4. **Múltiplos Downloads**: Pode baixar vários vídeos ou playlists
5. **Preservação de Metadados**: Salva título, descrição e miniatura

## Como Usar

### Download Básico

Download this YouTube video: https://youtube.com/watch?v=...

## Notas Importantes

⚠️ **Direitos Autorais e Uso Justo**
- Baixe apenas vídeos com permissão para download
- Respeite as leis de direitos autorais e termos de serviço da plataforma
- Use para fins pessoais, educacionais ou de uso justo
- Não redistribua conteúdo protegido por direitos autorais

## Dicas

- Especifique a qualidade se precisar de tamanho de arquivo menor (720p vs 1080p)
- Use apenas áudio para podcasts ou música para economizar espaço
- Baixe para uma pasta dedicada para manter a organização
- Verifique o tamanho do arquivo antes de baixar em conexões lentas

## Casos de Uso Comuns

- **Educação**: Salve tutoriais e cursos para aprendizado offline
- **Pesquisa**: Archive vídeos para referência
- **Criação de Conteúdo**: Baixe seu próprio conteúdo de plataformas
- **Backup**: Salve vídeos importantes antes de serem removidos
- **Visualização Offline**: Assista vídeos sem acesso à internet
