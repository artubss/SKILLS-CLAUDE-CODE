# Princípios de Design de Jogos

> Design thinking para jogos envolventes.

---

## 1. Design do Loop Principal

### O Teste dos 30 Segundos

```
Todo jogo precisa de um loop divertido de 30 segundos:
1. AÇÃO → Jogador faz algo
2. FEEDBACK → Jogo responde
3. RECOMPENSA → Jogador se sente bem
4. REPETIR
```

### Exemplos de Loops

| Gênero | Loop Principal |
|--------|-----------------|
| Platformer | Correr → Pular → Aterrissar → Coletar |
| Shooter | Mirar → Atirar → Eliminar → Saquear |
| Puzzle | Observar → Pensar → Resolver → Avançar |
| RPG | Explorar → Lutar → Subir Nível → Equipamento |

## 2. Game Design Document (GDD)

### Seções Essenciais

| Seção | Conteúdo |
|-------|----------|
| **Pitch** | Descrição em uma frase |
| **Loop Principal** | Gameplay de 30 segundos |
| **Mecânicas** | Como os sistemas funcionam |
| **Progressão** | Como o jogador avança |
| **Estilo de Arte** | Direção visual |
| **Áudio** | Direção sonora |

### Princípios

- Mantenha vivo (atualize regularmente)
- Elementos visuais ajudam na comunicação
- Menos é mais (comece pequeno)

## 3. Psicologia do Jogador

### Tipos de Motivação

| Tipo | Motivado Por |
|------|--------------|
| **Conquistador** | Objetivos, conclusão |
| **Explorador** | Descoberta, segredos |
| **Socializador** | Interação, comunidade |
| **Competidor** | Competição, dominância |

### Cronogramas de Recompensa

| Cronograma | Efeito | Uso |
|------------|--------|-----|
| **Fixo** | Previsível | Recompensas de marco |
| **Variável** | Viciante | Drops de loot |
| **Razão** | Baseado em esforço | Jogos de grind |

## 4. Balanceamento de Dificuldade

### Estado de Fluxo

```
Muito Difícil → Frustração → Sair
Muito Fácil → Tédio → Sair
Equilibrado → Fluxo → Engajamento
```

### Estratégias de Balanceamento

| Estratégia | Como |
|------------|------|
| **Dinâmica** | Ajuste à habilidade do jogador |
| **Seleção** | Deixe o jogador escolher |
| **Acessibilidade** | Opções para todos |

---

## 5. Design de Progressão

### Tipos de Progressão

| Tipo | Exemplo |
|------|---------|
| **Habilidade** | Jogador melhora |
| **Poder** | Personagem fica mais forte |
| **Conteúdo** | Novas áreas desbloqueadas |
| **História** | Narrativa avança |

### Princípios de Pacing

- Vitórias rápidas (ganhe jogadores logo)
- Aumente o desafio gradualmente
- Pausas descansadas entre momentos de intensidade
- Escolhas significativas

---

## 6. Anti-Padrões

| ❌ Não Faça | ✅ Faça |
|-------------|---------|
| Design em isolamento | Teste com jogadores constantemente |
| Polish antes de diversão | Prototipe primeiro |
| Force um único jeito de jogar | Permita expressão do jogador |
| Puna excessivamente | Recompense o progresso |

---

> **Lembre-se:** Diversão é descoberta através de iteração, não projetada no papel.
