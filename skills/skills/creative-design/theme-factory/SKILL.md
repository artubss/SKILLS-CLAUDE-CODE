# Skill Theme Factory

Esta skill fornece uma coleção curada de temas profissionais de fontes e cores, cada um com paletas de cores cuidadosamente selecionadas e combinações de fontes complementares. Uma vez que um tema é escolhido, ele pode ser aplicado a qualquer artefato.

## Objetivo

Use esta skill para aplicar estilo consistente e profissional a decks de slides de apresentação e outros artefatos. Cada tema inclui:
- Uma paleta de cores coesa com códigos hex
- Combinações de fontes complementares para títulos e corpo de texto
- Uma identidade visual distinta adequada para diferentes contextos e públicos

## Instruções de Uso

Para aplicar estilo a um deck de slides ou outro artefato:

1. **Exiba o showcase de temas**: Mostre o arquivo `theme-showcase.pdf` para permitir que os usuários vejam todos os temas disponíveis visualmente. Não faça nenhuma modificação; simplesmente mostre o arquivo para visualização.
2. **Peça a escolha deles**: Pergunte qual tema aplicar ao deck
3. **Aguarde a seleção**: Obtenha confirmação explícita sobre o tema escolhido
4. **Aplique o tema**: Uma vez que um tema foi escolhido, aplique as cores e fontes do tema selecionado ao deck/artefato

## Detalhes dos Temas

Cada tema é definido no diretório `themes/` com especificações completas, incluindo:
- Paleta de cores coesa com códigos hex
- Combinações de fontes complementares para títulos e corpo de texto
- Identidade visual distinta adequada para diferentes contextos e públicos

## Processo de Aplicação

Após um tema preferido ser selecionado:
1. Leia o arquivo de tema correspondente no diretório `themes/`
2. Aplique as cores e fontes especificadas consistentemente em todo o deck
3. Garanta contraste adequado e legibilidade
4. Mantenha a identidade visual do tema em todos os slides

## Crie seu Próprio Tema
Para lidar com casos em que nenhum dos temas existentes funciona para um artefato, crie um tema personalizado. Com base nas entradas fornecidas, gere um novo tema similar aos acima. Dê ao tema um nome similar descrevendo o que as combinações de fonte/cor representam. Use qualquer descrição básica fornecida para escolher cores/fontes apropriadas. Após gerar o tema, mostre-o para revisão e verificação. Em seguida, aplique o tema conforme descrito acima.
