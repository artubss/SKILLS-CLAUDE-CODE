# Fundamentos de SEO

> Princípios para visibilidade em mecanismos de busca.

---

## 1. Framework E-E-A-T

| Princípio | Sinais |
|-----------|---------|
| **Experience** | Conhecimento de primeira mão, exemplos reais |
| **Expertise** | Credenciais, profundidade de conhecimento |
| **Authoritativeness** | Backlinks, menções, reconhecimento da indústria |
| **Trustworthiness** | HTTPS, transparência, informações precisas |

---

## 2. Core Web Vitals

| Métrica | Meta | Mede |
|---------|------|------|
| **LCP** | < 2,5s | Desempenho de carregamento |
| **INP** | < 200ms | Interatividade |
| **CLS** | < 0,1 | Estabilidade visual |

---

## 3. Princípios de SEO Técnico

### Estrutura do Site

| Elemento | Propósito |
|----------|-----------|
| XML sitemap | Ajudar rastreamento |
| robots.txt | Controlar acesso |
| Canonical tags | Prevenir duplicatas |
| HTTPS | Sinal de segurança |

### Desempenho

| Fator | Impacto |
|-------|--------|
| Velocidade da página | Core Web Vital |
| Mobile-friendly | Fator de classificação |
| URLs limpas | Rastreabilidade |

---

## 4. Princípios de SEO de Conteúdo

### Elementos da Página

| Elemento | Melhor Prática |
|----------|----------------|
| Title tag | 50-60 caracteres, palavra-chave na frente |
| Meta description | 150-160 caracteres, atrativa |
| H1 | Um por página, palavra-chave principal |
| H2-H6 | Hierarquia lógica |
| Alt text | Descritivo, sem excesso |

### Qualidade do Conteúdo

| Fator | Importância |
|-------|-------------|
| Profundidade | Cobertura abrangente |
| Atualização | Atualizações regulares |
| Originalidade | Valor original |
| Legibilidade | Escrita clara |

## 5. Tipos de Schema Markup

| Tipo | Uso |
|------|-----|
| Article | Posts de blog, notícias |
| Organization | Informações da empresa |
| Person | Perfis de autores |
| FAQPage | Conteúdo de Q&A |
| Product | E-commerce |
| Review | Avaliações |
| BreadcrumbList | Navegação |

---

## 6. Diretrizes de Conteúdo com IA

### O que o Google Procura

| ✅ Faça | ❌ Não Faça |
|--------|------------|
| Rascunho de IA + edição humana | Publicar conteúdo bruto de IA |
| Adicionar insights originais | Copiar sem valor |
| Revisão de especialista | Pular verificação de fatos |
| Seguir E-E-A-T | Keyword stuffing |

---

## 7. Fatores de Classificação (Priorizados)

| Prioridade | Fator |
|------------|-------|
| 1 | Conteúdo de qualidade e relevante |
| 2 | Backlinks de sites de autoridade |
| 3 | Experiência da página (Core Web Vitals) |
| 4 | Otimização mobile |
| 5 | Fundamentos técnicos de SEO |

---

## 8. Medição

| Métrica | Ferramenta |
|--------|-----------|
| Classificações | Search Console, Ahrefs |
| Tráfego | Analytics |
| Core Web Vitals | PageSpeed Insights |
| Indexação | Search Console |
| Backlinks | Ahrefs, Semrush |

---

> **Lembre-se:** SEO é um jogo de longo prazo. Conteúdo de qualidade + excelência técnica + paciência = resultados.
