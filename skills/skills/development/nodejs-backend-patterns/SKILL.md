# Padrões de Backend Node.js

Orientação abrangente para construir aplicações backend Node.js escaláveis, mantíveis e prontas para produção com frameworks modernos, padrões arquiteturais e boas práticas.

## Use esta skill quando

- Estiver construindo APIs REST ou servidores GraphQL
- Criando microsserviços com Node.js
- Implementando autenticação e autorização
- Projetando arquiteturas backend escaláveis
- Configurando middleware e tratamento de erros
- Integrando bancos de dados (SQL e NoSQL)
- Construindo aplicações em tempo real com WebSockets
- Implementando processamento de jobs em background

## Não use esta skill quando

- A tarefa não está relacionada a padrões de backend Node.js
- Você precisa de um domínio ou ferramenta diferente fora deste escopo

## Instruções

- Esclareça objetivos, restrições e inputs necessários.
- Aplique as boas práticas relevantes e valide os resultados.
- Forneça passos acionáveis e verificação.
- Se exemplos detalhados forem necessários, abra `resources/implementation-playbook.md`.
