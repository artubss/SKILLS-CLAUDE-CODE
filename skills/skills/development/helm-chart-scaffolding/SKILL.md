# Helm Chart Scaffolding

Orientação abrangente para criar, organizar e gerenciar gráficos Helm para empacotar e implantar aplicações Kubernetes.

## Use essa skill quando

Use essa skill quando você precisar:
- Criar novos gráficos Helm do zero
- Empacotar aplicações Kubernetes para distribuição
- Gerenciar implantações multi-ambiente com Helm
- Implementar templating para manifestos Kubernetes reutilizáveis
- Configurar repositórios de gráficos Helm
- Seguir as melhores práticas e convenções do Helm

## Não use essa skill quando

- A tarefa não estiver relacionada ao scaffolding de gráficos Helm
- Você precisar de uma ferramenta ou domínio diferente fora do escopo

## Instruções

- Esclareça objetivos, restrições e entradas necessárias.
- Aplique as melhores práticas relevantes e valide os resultados.
- Forneça passos práticos e verificação.
- Se exemplos detalhados forem necessários, abra `resources/implementation-playbook.md`.
