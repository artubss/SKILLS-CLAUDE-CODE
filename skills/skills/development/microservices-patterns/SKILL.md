# Padrões de Microsserviços

Domine padrões de arquitetura de microsserviços incluindo limites de serviço, comunicação entre serviços, gerenciamento de dados e padrões de resiliência para construir sistemas distribuídos.

## Use esta skill quando

- Decompor monólitos em microsserviços
- Projetar limites de serviço e contratos
- Implementar comunicação entre serviços
- Gerenciar dados distribuídos e transações
- Construir sistemas distribuídos resilientes
- Implementar service discovery e load balancing
- Projetar arquiteturas event-driven

## Não use esta skill quando

- O sistema é pequeno o suficiente para um monólito modular
- Você precisa de um protótipo rápido sem complexidade distribuída
- Não há suporte operacional para sistemas distribuídos

## Instruções

1. Identifique limites de domínio e propriedade para cada serviço.
2. Defina contratos, propriedade de dados e padrões de comunicação.
3. Planeje resiliência, observabilidade e estratégia de deployment.
4. Forneça etapas de migração e proteções operacionais.
