# codex-review

## Visão Geral
Revisão profissional de código com geração automática de CHANGELOG, integrado com Codex AI

## Quando Usar
- Quando você quer revisão profissional de código antes de commits
- Quando você precisa de geração automática de CHANGELOG
- Quando revisando refatoração em larga escala

## Instalação
```bash
npx skills add -g BenedictKing/codex-review
```

## Guia Passo a Passo
1. Instale a skill usando o comando acima
2. Certifique-se de que Codex CLI está instalado
3. Use `/codex-review` ou triggers em linguagem natural
