# Excelência em Revisão de Código

Transforme revisões de código de uma barreira para compartilhamento de conhecimento através de feedback construtivo, análise sistemática e melhoria colaborativa.

## Use esta competência quando

- Revisar pull requests e mudanças de código
- Estabelecer padrões de revisão de código
- Orientar desenvolvedores através de feedback de revisão
- Auditar correção, segurança ou performance

## Não use esta competência quando

- Não há mudanças de código para revisar
- A tarefa é apenas uma discussão de design sem código
- Você precisa implementar correções em vez de revisar

## Instruções

- Leia contexto, requisitos e sinais de teste primeiro.
- Revise para correção, segurança, performance e manutenibilidade.
- Forneça feedback acionável com severidade e fundamentação.
- Faça perguntas esclarecedoras quando a intenção não for clara.
- Se forem necessários checklists detalhados, abra `resources/implementation-playbook.md`.

## Formato de Saída

- Resumo de alto nível dos achados
- Problemas agrupados por severidade (bloqueador, importante, menor)
- Sugestões e perguntas
- Notas sobre testes e cobertura
