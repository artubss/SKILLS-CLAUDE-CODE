# exa-search

## Visão Geral
Busca semântica, descoberta de conteúdo similar e pesquisa estruturada usando a API Exa

## Quando Usar
- Quando você precisa de busca baseada em semântica/embeddings
- Quando encontrar conteúdo similar
- Quando pesquisar por categoria (empresa, pessoas, artigos de pesquisa, etc.)

## Instalação
```bash
npx skills add -g BenedictKing/exa-search
```

## Guia Passo a Passo
1. Instale a skill usando o comando acima
2. Configure a chave API do Exa
3. Use naturalmente em conversas do Claude Code
