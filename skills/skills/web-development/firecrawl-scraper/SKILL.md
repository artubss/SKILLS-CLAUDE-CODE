# firecrawl-scraper

## Visão Geral
Raspagem profunda da web, captura de tela, análise de PDF e rastreamento de sites usando a API Firecrawl

## Quando Usar
- Quando você precisa de extração profunda de conteúdo de páginas web
- Quando interação com a página é necessária (cliques, rolagem, etc.)
- Quando você quer captura de tela ou análise de PDF
- Quando fazendo raspagem em lote de múltiplas URLs

## Instalação
```bash
npx skills add -g BenedictKing/firecrawl-scraper
```

## Guia Passo a Passo
1. Instale a skill usando o comando acima
2. Configure a chave de API Firecrawl
3. Use naturalmente em conversas Claude Code
