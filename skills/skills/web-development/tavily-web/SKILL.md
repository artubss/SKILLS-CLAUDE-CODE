# tavily-web

## Visão Geral
Capacidades de busca na web, extração de conteúdo, crawling e pesquisa usando a API Tavily

## Quando Usar
- Quando você precisa buscar na web por informações atualizadas
- Quando extrair conteúdo de URLs
- Quando fazer crawling de sites

## Instalação
```bash
npx skills add -g BenedictKing/tavily-web
```

## Guia Passo a Passo
1. Instale a skill usando o comando acima
2. Configure a chave de API da Tavily
3. Use naturalmente em conversas do Claude Code
