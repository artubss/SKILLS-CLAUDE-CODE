# Tailwind Design System

Crie design systems prontos para produção com Tailwind CSS, incluindo design tokens, variantes de componentes, padrões responsivos e acessibilidade.

## Use essa skill quando

- Criar uma biblioteca de componentes com Tailwind
- Implementar design tokens e temas
- Construir componentes responsivos e acessíveis
- Padronizar padrões de UI em toda uma codebase
- Migrar para ou estender Tailwind CSS
- Configurar dark mode e esquemas de cores

## Não use essa skill quando

- A tarefa não é relacionada a design system Tailwind
- Você precisa de um domínio ou ferramenta diferente fora desse escopo

## Instruções

- Esclareça objetivos, restrições e inputs necessários.
- Aplique práticas recomendadas relevantes e valide resultados.
- Forneça etapas acionáveis e verificação.
- Se exemplos detalhados forem necessários, abra `resources/implementation-playbook.md`.
