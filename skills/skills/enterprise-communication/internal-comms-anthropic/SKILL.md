## Quando usar essa skill
Para escrever comunicações internas, use essa skill para:
- Atualizações 3P (Progresso, Planos, Problemas)
- Newsletters da empresa
- Respostas de FAQ
- Relatórios de status
- Atualizações para liderança
- Atualizações de projetos
- Relatórios de incidentes

## Como usar essa skill

Para escrever qualquer comunicação interna:

1. **Identifique o tipo de comunicação** a partir da solicitação
2. **Carregue o arquivo de diretrizes apropriado** do diretório `examples/`:
    - `examples/3p-updates.md` - Para atualizações de equipe Progresso/Planos/Problemas
    - `examples/company-newsletter.md` - Para newsletters em toda a empresa
    - `examples/faq-answers.md` - Para responder perguntas frequentes
    - `examples/general-comms.md` - Para qualquer coisa que não corresponda explicitamente a uma das opções acima
3. **Siga as instruções específicas** naquele arquivo para formatação, tom e coleta de conteúdo

Se o tipo de comunicação não corresponder a nenhuma diretriz existente, solicite esclarecimentos ou mais contexto sobre o formato desejado.
