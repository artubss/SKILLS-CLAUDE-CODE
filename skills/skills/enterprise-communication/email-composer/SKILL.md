# Compositor de E-mails

## Início rápido

Forneça contexto e objetivo, e vou redigir um e-mail apropriado.

**O que preciso:**
- Objetivo do e-mail (solicitação, acompanhamento, anúncio, etc.)
- Relacionamento com o destinatário (colega, cliente, gerente, fornecedor)
- Pontos-chave a incluir
- Tom desejado (formal, casual, urgente, amigável)

## Estrutura de e-mail

Formato padrão de e-mail profissional:

```
Assunto: [Linha de assunto clara e específica]

[Saudação],

[Abertura - contexto/objetivo]

[Corpo - pontos principais]

[Encerramento - chamada para ação]

[Despedida]
[Seu nome]
```

## Tipos de e-mail comuns

### Solicitação de informações

```
Assunto: Dúvida sobre cronograma do projeto Q4

Oi [Nome],

Espero que você esteja bem. Estou entrando em contato sobre o cronograma do lançamento do produto Q4.

Você poderia fornecer uma atualização sobre:
- Progresso atual no desenvolvimento de funcionalidades
- Data esperada para conclusão da fase de testes
- Quaisquer obstáculos ou dependências que devemos considerar

Isso nos ajudará a coordenar com a equipe de marketing sobre os materiais de lançamento.

Obrigado antecipadamente pela ajuda!

Atenciosamente,
[Seu nome]
```

### E-mail de acompanhamento

```
Assunto: Acompanhamento: Proposta para novo sistema de pagamento

Oi [Nome],

Gostaria de acompanhar a proposta de sistema de pagamento que enviei semana passada. Entendo que você está ocupado, então quis garantir que ela não se perdeu na sua caixa de entrada.

- Reduzirá taxas de transação em 30%

- Melhorará a experiência de checkout dos clientes

Tenho prazer em agendar uma breve ligação para discutir qualquer dúvida.

Fico no aguardo do seu retorno.

Abraços,
[Seu nome]
```

### Atualização técnica

```
Assunto: Janela de manutenção da API - [Data]

Time,

Este é um lembrete de que realizaremos manutenção programada na infraestrutura de nossa API em [Data] de [Hora] a [Hora] [Fuso horário].

Durante esta janela:
- Endpoints da API estarão indisponíveis
- Banco de dados será atualizado para v14
- Certificados SSL serão renovados

O que você precisa fazer:
- Notificar seus usuários sobre o tempo de inatividade programado

- Monitorar sua aplicação após a conclusão da manutenção

Se você tiver preocupações ou conflitos com este cronograma, por favor me avise até [Data].

Detalhes técnicos disponíveis em nossa página de status: [link]

Obrigado,
[Seu nome]
```

### Solicitação de reunião

```
Assunto: Solicitação de reunião: Discutir estratégia de migração de banco de dados

Oi [Nome],

Gostaria de agendar uma reunião para discutir nossa abordagem para a próxima migração de banco de dados.

Itens da agenda:
- Revisar cronograma de migração e marcos
- Discutir estratégia de reversão
- Identificar riscos potenciais e planos de mitigação
- Atribuir responsabilidades do time

Duração estimada: 45 minutos

Estou disponível:
- Segunda-feira 14h-16h
- Quarta-feira 10h-12h
- Sexta-feira 13h-15h

Por favor, me diga o que funciona melhor para você ou sinta-se à vontade para sugerir outros horários.

Abraços,
[Seu nome]
```

## Diretrizes de tom

### Tom formal
- Use frases completas
- Evite contrações
- Linguagem profissional
- Títulos apropriados (Dr., Sr., Sra.)

### Tom casual
- Contrações aceitáveis
- Linguagem conversacional
- Ainda profissional
- Nomes próprios

### Tom urgente
- Linha de assunto clara com [URGENTE] ou [AÇÃO REQUERIDA]
- Pontos-chave em negrito
- Prazo explícito
- Chamada para ação direta

## Boas práticas de linha de assunto

**Boas linhas de assunto:**
- "Ação requerida: Enviar folha de ponto até sexta"
- "Relatório de vendas Q4 - Revisão necessária"
- "Reunião remarcada: Kickoff do projeto agora na quinta"
- "Dúvida rápida sobre processo de deploy"

**Más linhas de assunto:**
- "Atualização"
- "Dúvida"
- "Oi"
- "Acompanhamento"

## Etiqueta de e-mail

**FAÇA:**
- Responda em até 24 horas (mesmo que apenas para reconhecer)
- Use linhas de assunto claras e específicas
- Mantenha-se conciso
- Revise antes de enviar
- Inclua contexto relevante
- Use listas com bullets para múltiplos itens
- Termine com chamada para ação clara

**NÃO FAÇA:**
- Use TUDO EM MAIÚSCULAS
- Abuse de pontos de exclamação!!!
- Marque tudo como urgente
- Responda a todos desnecessariamente
- Envie quando emocionalmente afetado
- Inclua destinatários desnecessários
- Esqueça anexos mencionados no e-mail

## Templates por cenário

### Recuse uma solicitação com educação

```
Assunto: Re: [Assunto original]

Oi [Nome],

Obrigado por pensar em mim para [solicitação/oportunidade].

Infelizmente, não poderei [participar/ajudar/comparecer] devido a [motivo breve - opcional]. Porém, gostaria de sugerir [sugestão alternativa se aplicável].

Agradeço sua compreensão, e espero que possamos colaborar em oportunidades futuras.

Atenciosamente,
[Seu nome]
```

### Peça desculpas por um erro

```
Assunto: Desculpas e correção: [Problema]

Oi [Nome],

Estou escrevendo para me desculpar por [erro específico]. Foi um erro da minha parte, e assumo total responsabilidade.

Para corrigir isso:
- [Ação 1 já tomada]
- [Ação 2 em andamento]
- [Medida preventiva para o futuro]

Entendo que isso pode ter causado [impacto], e me comprometo a garantir que não aconteça novamente.

Se você tiver alguma preocupação ou dúvida, não hesite em entrar em contato.

Atenciosamente,
[Seu nome]
```

### Compartilhe uma boa notícia

```
Assunto: Ótima notícia: [Conquista/marco]

Time,

Fico feliz em compartilhar que [conquistamos objetivo]!

Este sucesso é graças a:
- [Contribuição do time/pessoa 1]
- [Contribuição do time/pessoa 2]

Impacto:
- [Melhoria de métrica]
- [Benefício comercial]

Obrigado a todos pela dedicação e esforço. Vamos manter esse ritmo!

Abraços,
[Seu nome]
```

- Abraços

## Checklist de composição de e-mail

- [ ] Linha de assunto clara e específica
- [ ] Saudação apropriada
- [ ] Objetivo declarado no início
- [ ] Pontos-chave organizados com bullets/números
- [ ] Chamada para ação ou próximos passos claros
- [ ] Tom apropriado para o público
- [ ] Revisado quanto a erros de digitação
- [ ] Anexos inclusos (se mencionados)
- [ ] Destinatários corretos (Para, CC, CCO)
- [ ] Assinatura profissional
