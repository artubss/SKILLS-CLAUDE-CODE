# context7-auto-research

## Visão Geral
Buscar automaticamente documentação atualizada de bibliotecas e frameworks para Claude Code via API Context7

## Quando Usar
- Quando você precisa de documentação atualizada para bibliotecas e frameworks
- Ao fazer perguntas sobre React, Next.js, Prisma ou qualquer outra biblioteca popular

## Instalação
```bash
npx skills add -g BenedictKing/context7-auto-research
```

## Guia Passo a Passo
1. Instale a skill usando o comando acima
2. Configure a chave de API (opcional, veja o repositório GitHub para detalhes)
3. Use naturalmente em conversas do Claude Code
